# Разбивка ФИО и склонение должностей

Веб-версия Excel-макроса `SplitFIO2` плюс склонение должностей в дательный падеж.

Из полного ФИО получает:

| Колонка | Пример |
|---|---|
| Фамилия И.О. (дат.) | Иванову И.И. |
| Имя Отчество | Иван Иванович |
| Окончание | ый / ая |
| Обращение | Уважаемый Иван Иванович |

Из должности в именительном падеже — должность в дательном: «Генеральный директор» → «Генеральному директору». Если в файле указаны обе колонки, добавляется готовая строка **Кому**: «Генеральному директору Иванову И.И.».

Три способа работы: одна запись, список строк, файл (xlsx / xlsm / xls / csv) с выгрузкой результата в Excel или CSV.

**Две колонки сразу.** Если в файле должность и ФИО идут парой, на вкладке «Файл» выбираются обе колонки (приложение пытается угадать их по заголовкам) — строки обрабатываются построчно и не перемешиваются. На вкладке «Список строк» есть режим «Должность + ФИО»: можно скопировать из Excel сразу две колонки и вставить — разделитель Tab, `;` или `|` распознаётся сам.

## Регистр

Должность всегда приводится к виду «первая буква заглавная, остальные строчные». Не понижаются: аббревиатуры (ООО, ПТО, HR, IT), слова в кавычках и название организации сразу после правовой формы — «Главный бухгалтер ООО «Ромашка»». Отключается тумблером «Исправлять регистр».

## Опечатки

Тумблер «Исправлять опечатки» (по умолчанию включён). Каждая правка попадает в колонку «Комментарий», так что результат можно отфильтровать и проверить.

- **Должности** — словарь частых опечаток (`дирекор`, `бухалтер`, `заместиель`, `инжинер` и т. п.) плюс нечёткое сравнение со словарём правильных слов.
- **Свой справочник.** В боковой панели можно загрузить xlsx/csv с эталонными должностями — тогда строка сначала ищется в справочнике целиком (точно, потом с допуском), и приводится к вашей эталонной формулировке. Это даёт нормализацию заодно с исправлением опечаток.
- **Имена и отчества** — отчество, соответствующее шаблону (`-ович/-евич/-овна/-евна/-ич/-оглы/-кызы`), не трогается вообще; остальное правится по окончанию (`Ивановичь → Иванович`) и по списку имён (`Сергеивна → Сергеевна`, `Александер → Александр`).
- **Фамилии не проверяются никогда** — отличить опечатку от редкой фамилии невозможно.

Проверка на 1110 реальных ФИО из рабочего файла: ложных «исправлений» — 0.

## Правила

**Пол** определяется по отчеству: `-вич, -тич, -мич, -ьич, -ич, -оглы, -улы, -уулу` → мужской; `-вна, -чна, -шна, -кызы, -гызы` → женский.

**Дательный падеж фамилии:**

- не склоняются: на `-о, -е, -и, -у, -ы, -ых, -их` и женские на согласную, `-й`, `-ь`;
- женские: `Иванова → Ивановой`, `Белая → Белой`;
- мужские: `Иванов → Иванову`, `Гоголь → Гоголю`, `Толстой → Толстому`, `Белый → Белому`, `Гайдай → Гайдаю`;
- двойные фамилии через дефис склоняются по частям.

Сомнительные случаи не пропускаются молча — строка попадает в результат с пометкой в колонке «Комментарий» (мужские фамилии на `-а/-я`, беглая гласная в `-ок/-ец`, ФИО длиннее трёх слов, отсутствие отчества, неопределённый пол).

## Склонение должностей

Склоняется только «вершина» должности — идущие подряд прилагательные и первое существительное. Всё, что идёт дальше (родительный падеж, предлоги, названия организаций), остаётся без изменений:

| Было | Стало |
|---|---|
| Генеральный директор | Генеральному директору |
| Начальник отдела продаж | Начальнику отдела продаж |
| Заместитель генерального директора по экономике | Заместителю генерального директора по экономике |
| Заведующий отделением | Заведующему отделением |
| Старшая медицинская сестра | Старшей медицинской сестре |
| Продавец-консультант | Продавцу-консультанту |
| Директор ООО «Ромашка» | Директору ООО «Ромашка» |

Должности, начинающиеся с «и.о.», «врио», «исполняющий обязанности», а также с сокращений вроде «Зам.», остаются как есть — там дальше уже стоит родительный падеж.

## Режим «как в макросе»

Переключатель в боковой панели возвращает поведение исходного VBA один в один: строки без отчества / с нестандартным отчеством / длиннее трёх слов пропускаются, правила склонения — старые. Проверено на выгрузке из рабочего файла: на 1110 строках расхождений с макросом нет.

Обычный режим отличается от макроса примерно в 3 % строк, и все отличия — исправления: `Бережною → Бережному`, `Доровскою → Доровскому`, `Губеладзеу → Губеладзе`, `Гертьеу → Гертье`, `Зозуляу → Зозуле`, `Голота → Голоте`, плюс обрабатываются строки, которые макрос пропускал.
