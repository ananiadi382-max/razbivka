# Разбивка ФИО

Веб-версия Excel-макроса `SplitFIO2`. Из полного ФИО получает:

| Колонка | Пример |
|---|---|
| Фамилия И.О. (дат.) | Иванову И.И. |
| Имя Отчество | Иван Иванович |
| Окончание | ый / ая |
| Обращение | Уважаемый Иван Иванович |

Три способа работы: одно ФИО, список строк, файл (xlsx / xlsm / xls / csv) с выгрузкой результата в Excel или CSV.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Публикация для сотрудников

1. Создать репозиторий на GitHub и залить в него `app.py`, `fio_utils.py`, `requirements.txt`, `.streamlit/config.toml`, `README.md`.
2. Зайти на [share.streamlit.io](https://share.streamlit.io) под тем же GitHub-аккаунтом → **Create app** → выбрать репозиторий, ветку `main`, Main file path — `app.py`.
3. Deploy. Ссылку вида `https://<имя>.streamlit.app` раздать сотрудникам — ничего устанавливать им не нужно.

Секретов и API здесь нет, всё считается на стороне приложения, данные никуда не отправляются (файл живёт только в оперативной памяти сессии).

## Правила

**Пол** определяется по отчеству: `-вич, -тич, -мич, -ьич, -ич, -оглы, -улы, -уулу` → мужской; `-вна, -чна, -шна, -кызы, -гызы` → женский.

**Дательный падеж фамилии:**

- не склоняются: на `-о, -е, -и, -у, -ы, -ых, -их` и женские на согласную, `-й`, `-ь`;
- женские: `Иванова → Ивановой`, `Белая → Белой`;
- мужские: `Иванов → Иванову`, `Гоголь → Гоголю`, `Толстой → Толстому`, `Белый → Белому`, `Гайдай → Гайдаю`;
- двойные фамилии через дефис склоняются по частям.

Сомнительные случаи не пропускаются молча — строка попадает в результат с пометкой в колонке «Комментарий» (мужские фамилии на `-а/-я`, беглая гласная в `-ок/-ец`, ФИО длиннее трёх слов, отсутствие отчества, неопределённый пол).

## Режим «как в макросе»

Переключатель в боковой панели возвращает поведение исходного VBA один в один: строки без отчества / с нестандартным отчеством / длиннее трёх слов пропускаются, правила склонения — старые. Проверено на выгрузке из рабочего файла: на 1110 строках расхождений с макросом нет.

Обычный режим отличается от макроса примерно в 3 % строк, и все отличия — исправления: `Бережною → Бережному`, `Доровскою → Доровскому`, `Губеладзеу → Губеладзе`, `Гертьеу → Гертье`, `Зозуляу → Зозуле`, `Голота → Голоте`, плюс обрабатываются строки, которые макрос пропускал.
